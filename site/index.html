A note for learners and grown-ups

Some lessons may use software accounts, downloads, or services that cost money. Ask a trusted adult before signing up, spending money, sharing work publicly, or sending personal information anywhere. Our first big question

What happens when you ask AI a question?

A language model uses patterns learned from examples to guess what text should come next. That can be powerful—but a good guess is not the same thing as a checked fact.

1. A learned recipe

A trained model contains a huge set of numbers that capture patterns. They do not change just because you asked a question.

2. Text becomes small pieces

Before the model handles text, a tool splits it into numbered pieces called tokens. A piece might be a whole word or part of one.

3. One piece at a time

The model estimates which next piece might fit, chooses one, and repeats. The estimates are probabilities: a useful guess, not a promise of truth.

4. A limited reading space

A model can only handle a limited amount of text at once. That limit is its context window. Some services charge for use, so an adult should help with any account or spending.

5. A helper with a book

A program can search a set of notes and show useful passages alongside a question. This is called retrieval-augmented generation, or RAG. We still have to check whether the model used the notes correctly.

6. A guess is not a fact

A confident answer can still be wrong. We can test answers against examples and sources, protect private information, and learn where the program needs better limits.

A habit for curious builders

Make a fair test for your idea

One lucky answer does not prove a program works. Try several examples, write down what you expected, change one thing, then compare.

Your experiment notebook

Before changing your project, write what you think will happen. Afterward, check what actually happened. Surprises are discoveries, not failures.

  • Pick a question: What should your project help someone do?
  • Make a few examples: Write questions and note which source passage should help answer each one.
  • Compare fairly: Change one thing at a time. Did answers get more useful, less useful, or just different?
