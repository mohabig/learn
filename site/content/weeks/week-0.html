This is a friendly place to begin if coding is new, or a place to revisit anything that feels wobbly. Try a lesson and see what you learn; this is not a test, and there is no penalty for starting here. You will explore folders and terminal commands, make a small Python program, see how errors and tests help, look at a pretend web request, and practise saving versions of your work. Pause whenever you need. Ask a trusted adult before installing software, making an account, or using an online service.
